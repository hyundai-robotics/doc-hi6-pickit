USB를 사용하여 TP 화면을 통해 플러그인 설치를 진행합니다.  



<div style="max-width:fit-content;">

|Step|내용|
|:---: |:---|
| `1` | pick-it 플러그인 프로그램을 USB 에 저장합니다.  |
| `2` | USB 를 TP에 연결합니다. |
| `3` | `서비스` > `5: 파일 관리` > `USB` > `pickit 폴더` > `복사` |
| `4` | `MAIN` > `apps` > `붙여넣기` |
| `5` | `제어기 재부팅` |
| `6` | `시스템` > `5: 응용 파라미터` > `픽잇` |
