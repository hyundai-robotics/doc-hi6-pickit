详细过程如下。

<div style="max-width:fit-content;">

|步骤|内容|
|---: |:---|
| `翻译 (1)` | 将pick-it插件程序保存到USB。 |
| `翻译 (2)` | 将USB连接到TP。 |
| `翻译 (3)` | `服务 (Service)` > `5: 文件管理器 (5: File manager)` > `USB` > `pickit`文件夹 > `复制 (copy)` |
| ` (4)` | `MAIN`文件夹 > `apps`文件夹 > `粘贴 (paste)` |
| ` (5)` | 重启${cont_model} COM |
| ` (6)` | `系统 (system)` > `4: 应用参数 (4: Application parameter)` > `25: pickit` |
